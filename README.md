# Booklly

Dashboard para controlar sua biblioteca pessoal, com livros que você quer ler, está lendo ou já concluiu.

## Tecnologias

- Front-end: HTML, CSS e JavaScript puro
- Back-end: Node.js com Express
- Banco de dados: PostgreSQL

## Visão geral

O Booklly é uma aplicação web para organizar a biblioteca pessoal com funcionalidades de:

- cadastro e login de usuário
- criação de conta
- listagem de livros por status
- adição, edição e remoção de livros
- controle de livros em três estados: quero ler, lendo e lido

## Estrutura do projeto

- `server.js`: configuração do servidor Express e endpoints da API
- `db.js`: conexão com o PostgreSQL
- `schema.sql`: estrutura das tabelas de usuários e livros
- `public/`: arquivos HTML, CSS e JavaScript do front-end
